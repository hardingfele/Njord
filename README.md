# Njord Weather – web app

The web version of Njord Weather, published with GitHub Pages at
https://hardingfele.github.io/Njord/

**iPhone:** open the link in Safari › Share › **Add to Home Screen**.
**Android:** open in Chrome › menu › **Add to Home screen** / **Install app**.

These files are copied from the app's source (`app/src/main/assets/web`).
Designed and directed by Aaran. Built with AI assistance (Claude and Copilot).
Weather data by Open-Meteo.com (CC BY 4.0); alerts from the US National Weather Service.
